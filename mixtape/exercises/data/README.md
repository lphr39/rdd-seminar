# Hansen teaching extract

[hansen_dwi.dta](hansen_dwi.dta) is the 214,558-observation teaching extract
used in Cunningham's course and in this seminar. It is included so a clone
contains the exercise data. It is not the original study's full replication data.

- **Teaching source:** [Cunningham's causal-inference-class repository](https://github.com/scunning1975/causal-inference-class/tree/20143dee51505d827f572f444ac93ca9ca5e31da).
- **Original study:** Hansen (2015), [Punishment and Deterrence: Evidence from Drunk Driving](https://doi.org/10.1257/aer.20130189).
- **Upstream repository licence:** MIT, copyright Scott Cunningham (2020). The
  unmodified notice is retained in [LICENSE.txt](LICENSE.txt).
- **Version and checksum:** recorded in [../sources.lock.json](../sources.lock.json).

The file is unchanged from the pinned teaching source. Run
`python fetch_sources.py --check` from the exercise directory to verify it.
The licence notice applies to the material obtained from that teaching source,
not to every third-party paper or figure elsewhere in this repository.
