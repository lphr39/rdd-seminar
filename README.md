# Regression Discontinuity Designs

Seminar materials by Luis P. de la Horra, Universidad de Valladolid.
Choose one of the two English teaching tracks:

| Track | Overview | Slides | Exercises |
|---|---|---|---|
| **Mixtape / Remix** | [Guide](mixtape/README.md) | [PDF](mixtape/presentation/slides.pdf), [LaTeX](mixtape/presentation/slides.tex) | [Instructions](mixtape/exercises/README.md), [worksheet](mixtape/exercises/WORKSHEET.md) |
| **Cattaneo, Idrobo, and Titiunik** | [Guide](cattaneo/README.md) | [PDF](cattaneo/presentation/slides.pdf), [LaTeX](cattaneo/presentation/slides.tex) | [Instructions](cattaneo/exercises/README.md), [worksheets](cattaneo/exercises/WORKSHEET.md) |

The Mixtape track is a short seminar with a Hansen exercise. The Cattaneo track
is a longer course based on *Foundations* (2020) and *Extensions* (2024).
Each guide describes its teaching sequence, timing, data, and build instructions.

Both tracks use the same folder layout and entry points: `presentation/slides.*`,
`presentation/build.py`, and `exercises/run_all.do`.

See [SOURCES.md](SOURCES.md) for readings, empirical studies, and attribution.
